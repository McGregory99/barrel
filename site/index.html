Your Steam library, one command away.

Barrel creates a Windows 10 bottle, installs Steam silently and applies the fixes Steam needs under Wine. Then it turns Steam into a Mac app with its own icon.

Recipes check every download against a pinned SHA-256.

The right engine for each game.

Keep a bottle on DXVK and move one game to DXMT, or send an old launcher back to wined3d. Overrides are per executable, so nothing else changes.

DXVK, DXMT and wined3d ship inside the app.

Every app in its own Windows.

A bottle has its own C: drive, registry and settings, so a broken install never touches anything else. Copy it, export it, restore it on another Mac.

Under the hood

Two translators.
One Mac.

A Windows game talks to Windows and to Direct3D. Barrel answers both: Wine speaks for Windows, DXVK or DXMT speak for Direct3D.

Wine 11

Implements the Windows API on macOS: windows, files, input, audio and networking. Built with CrossOver 26.3's open-source patches and run under Rosetta 2.

DXVK and DXMT

DXVK turns Direct3D 9–11 into Vulkan, which MoltenVK runs on Metal. DXMT goes from Direct3D 11 straight to Metal.

Barrel

Everything around them: bottles, recipes, per-game settings, Mac launchers and a self-contained runtime inside the app.

Performance

Free doesn’t
mean slower.

In the Stonewards main menu on an Apple M2, Barrel with DXMT spends less GPU time per frame than CrossOver 26 with D3DMetal, and uses about 40% less GPU memory than DXVK.

Small things,
done properly.

Launchers that look right.

A launcher is a real Mac app. Barrel reads the icon out of the Windows executable, so it looks right in the Dock and Spotlight.

Recipes you can read.

Installs are short JSON files: downloads with a pinned hash, silent installers, registry tweaks. Write your own in minutes.

Bottles you can take with you.

Export a bottle to a single .tar.gz, restore it on another Mac, or copy it before you try something risky.

A command line, too.

Everything in the app is one barrel command away, for scripts and for people who live in the terminal.
